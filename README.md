# Pluckyt

![Platform](https://img.shields.io/badge/OS-Windows-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**Pluckyt** is a modern, zero-install desktop application for downloading YouTube videos at maximum quality. Built with a clean, native-looking interface, it handles the complex backend work so you don't have to.

There is no need to use the terminal, install Python, or configure FFmpeg. Just download the app, paste a link, and pluck your video straight to your hard drive.

## ✨ Features

* **Zero Installation:** Runs entirely as a single executable file.
* **Maximum Quality:** Automatically downloads the best available video and audio streams (1080p, 4K) and merges them seamlessly.
* **Modern Interface:** A clean, responsive UI that matches your system's light/dark mode.
* **Custom Save Locations:** Choose exactly where your files go.
* **Safe & Verified:** Every release is automatically scanned via VirusTotal.

## 🚀 How to Use (For Regular Users)

1. Go to the [Releases page](../../releases/latest).
2. Download `Pluckyt.exe`.
3. Double-click the file to open the app (no installation required).
4. Select your save folder, paste a YouTube link, and click **Download**.
